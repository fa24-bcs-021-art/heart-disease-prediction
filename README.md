# Heart Disease Prediction System

AIC354 Machine Learning Fundamentals, Assignment 2 (Fall 2026).

Predicts heart disease (Yes/No) from 4 inputs (Age group, Max heart rate group, Sex, Exercise angina) using a Support Vector Classifier trained on the UCI Heart Disease (Cleveland) data.

- Heart_Disease_Prediction.ipynb : full notebook
- sample-data.csv : dataset with the 4 selected inputs
- svc_heart_trained_model.pkl : trained model
- streamlit-app/ : web app used for cloud deployment
